# Cooltomato_Oss

멋쟁이 토마토 오픈소스소프트웨어 과제

## 토마토 트레이드 V1

12월 2일 발표용 주식·코인 모의투자 웹사이트입니다. 대학생, 사회초년생, 직장인, 자유 설정 중 하나로 초기 투자금을 정하고 가상으로 매수·매도할 수 있습니다. Flask와 SQLite를 사용하며 한 PC에서 한 개의 모의 계좌를 운영합니다. 거래 수수료와 세금은 0원입니다.

## Windows에서 실행하기

1. Python 3.11 이상을 설치합니다. VS Code에서 프로젝트 폴더를 열고 **터미널 → 새 터미널**을 누릅니다.
2. PowerShell에서 아래 명령을 순서대로 실행합니다. `py` 명령이 설치되지 않았다면 첫 명령의 `py -3`을 `python`으로 바꿉니다.

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe app.py
   ```

3. 터미널에 `Running on http://127.0.0.1:5000`이 표시되면 브라우저에서 [http://127.0.0.1:5000](http://127.0.0.1:5000)을 엽니다. 시나리오 선택 화면이 나옵니다. 서버 종료는 터미널에서 `Ctrl+C`를 누릅니다.
4. `instance/portfolio.sqlite3`는 처음 실행할 때 생성됩니다. 서버를 다시 실행해도 기록이 유지됩니다. 웹에서 **내 자산 → 투자 초기화**를 실행하면 현금, 보유 종목과 거래 내역을 초기화합니다.

## 가격과 차트

| 종목 | 주문 기준 | 차트 |
| --- | --- | --- |
| BTC, ETH, XRP | Upbit 원화 마켓의 최근 체결가 | Upbit 원화 일봉 |
| AAPL, MSFT, TSLA | Alpha Vantage 최근 일별 종가 × 최근 조회한 USD/KRW 일별 환율 | Alpha Vantage 달러 종가 |
| 주식 데모 | 고정된 원화 예시 가격 | `데모 가격`이라고 표시한 가상 시계열 |

- Upbit 공개 조회는 키 없이 사용합니다. 코인 시세를 조회할 수 없으면 해당 종목의 주문이 잠시 중단됩니다. 보유한 코인의 시세가 없으면 총자산과 수익률도 계산을 보류합니다.
- 미국 주식 실제 종가와 환율을 사용하려면 [Alpha Vantage](https://www.alphavantage.co/support/#api-key)의 무료 키를 발급받아 서버를 시작할 PowerShell에서 설정합니다.

  ```powershell
  $env:ALPHA_VANTAGE_API_KEY = '발급받은_키'
  .\.venv\Scripts\python.exe app.py
  ```

- 키를 설정하지 않았거나 주가·환율 조회에 실패하면 **데모 가격**을 사용합니다. 화면과 거래 내역 모두에서 데모 체결을 구분합니다. 실제 종가는 USD로 들어오지만 가상 계좌의 결제 통화는 KRW입니다. API 호출 제한을 고려해 주식과 환율 일봉은 한 시간 동안 서버에 캐시합니다.
- 종목 화면을 열면 시세 기준과 조회 시점이 표시됩니다. 주문 시 서버의 가격이나 출처가 달라졌다면 변경된 조건을 확인한 뒤 주문합니다.
- Chart.js는 CDN을 사용합니다. CDN 접속에 실패하면 차트 위치에서 날짜별 가격 목록을 열 수 있습니다.
- 주식은 1주, 코인은 소수점 아래 8자리까지 입력합니다. 체결 금액은 원 단위 반올림하며 1원 미만으로 정산되는 주문은 거절합니다. 자산 화면의 평가손익은 보유분 기준이고, 전체 수익률에는 이미 매도한 거래의 영향도 반영됩니다.

## 테스트하기

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

자동 테스트는 임시 SQLite 파일과 예시 시세 응답으로 검증합니다. PC에서 실제 API를 확인하려면 다음 순서로 테스트합니다.

1. 대학생 시나리오를 선택하고 내 자산이 `1,000,000원`인지 확인합니다.
2. 종목 탐색에서 BTC의 **업비트 현재가**와 일봉을 확인하고 `0.001`을 매수·매도합니다. 시세 오류가 나면 주문이 비활성화되는지 확인합니다.
3. Alpha Vantage 키가 있는 상태에서 AAPL의 **Alpha Vantage 종가**, 기준일, 환율, USD 차트를 확인합니다. 키가 없는 상태로 서버를 재실행해 **데모 가격** 표시도 확인합니다.
4. AAPL `1주`를 매수·매도하고 거래 내역의 수량, 단가, 시세 출처를 확인합니다. `0.5주`와 보유량을 넘긴 매도는 오류 메시지가 표시되어야 합니다.
5. 서버를 다시 실행해 기록이 유지되는지 확인합니다. 투자 초기화 뒤에는 시나리오 선택 화면이 다시 열려야 합니다.

## 코드와 협업

| 경로 | 역할 |
| --- | --- |
| `app.py` | Flask 화면과 요청 처리 |
| `market.py` | 주식·코인 조회, 차트 데이터, 주식 데모 |
| `trading.py` | 거래 검증, 잔액·보유량 반영과 자산 계산 |
| `db.py` | SQLite 저장 구조와 트랜잭션 |
| `templates/`, `static/` | 한국어 웹 화면과 차트 |
| `tests/` | 거래, 가격 응답 처리, 화면 흐름 테스트 |
