# 토마토 트레이드 V1

멋쟁이 토마토 오픈소스소프트웨어 과제 · 12월 2일 발표

과거 시세로 매수·매도를 연습하는 모의투자 웹사이트입니다. Flask와 SQLite를 사용하며 한 PC에서 모의 계좌 하나를 운영합니다. 거래 수수료와 세금은 0원입니다.

## Windows에서 실행하기

1. Python 3.11 이상을 설치합니다. VS Code에서 프로젝트 폴더를 열고 **터미널 → 새 터미널**을 누릅니다.
2. PowerShell에 아래 명령을 순서대로 입력합니다. `py` 명령을 사용할 수 없으면 첫 줄의 `py -3`을 `python`으로 바꿉니다.

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe app.py
   ```

3. [http://127.0.0.1:5000](http://127.0.0.1:5000)을 열면 투자금과 시작 날짜 선택 화면이 나옵니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.
4. `instance/replay.sqlite3`에 날짜, 계좌, 거래, 평가 기록이 저장됩니다. 이전 버전의 `instance/portfolio.sqlite3`는 별도로 보존됩니다.

## 시연 순서

1. 대학생(100만 원), 사회초년생(500만 원), 직장인(1,000만 원), 자유 설정 중 하나를 선택합니다. 시작 날짜는 2024-01-01~2024-06-29입니다.
2. **종목 탐색 → BTC**에서 과거 종가와 차트를 확인하고 소량을 매수합니다. 주식은 실제 역사 주가·환율을 먼저 조회하며, 조회 실패 시 **데모 데이터** 안내와 **데모 가격** 출처를 표시합니다.
3. **내 자산 → +1일 / +7일 / +30일**을 눌러 자산 변화와 코치 피드백을 봅니다. 날짜는 앞으로만 이동하며 2024-06-30에서 멈춥니다. 해당 날짜에 가격이 있는 종목만 주문할 수 있습니다.
4. 거래 가능한 날에 일부를 매도한 뒤 **거래 내역**에서 투자 날짜, 체결가, 출처를 확인합니다.
5. **투자 종료**를 누르면 최종 수익률과 종합 코치 결과가 표시됩니다. 다시 시작하려면 **내 자산 → 투자 초기화**를 사용합니다. 초기화하면 이번 시뮬레이션의 거래와 평가 기록이 삭제됩니다.

## 가격과 계산 기준

| 종목 | 데이터 | 거래 가능한 날짜 |
| --- | --- | --- |
| BTC, ETH, XRP | [Upbit 원화 마켓 일봉 종가](https://docs.upbit.com/kr/reference/list-candles-days). 캔들 시작 날짜는 UTC 기준 | 해당 날짜의 일봉이 있는 날 |
| AAPL, MSFT, TSLA | Yahoo Finance 과거 USD 종가 × 과거 USD/KRW 환율 | 실제 주가 데이터에 종가가 있는 날 |
| 주식 조회 실패 시 | 원화로 만든 가상 가격. 화면에 **데모 데이터**, 가격·차트·거래 내역 출처에 **데모 가격** 표시 | 월~금. 실제 미국 거래소 공휴일은 반영하지 않음 |

- 해당 날짜의 일봉이 이미 마감된 시점으로 가정합니다. 주문은 당일 종가로 체결하고 차트는 현재 투자 날짜까지의 최근 30개 가격을 반환합니다.
- 코인은 API 키 없이 처음 열 때 조회하고 서버가 켜져 있는 동안 재사용합니다. 조회 실패 시 30초 후 다시 시도할 수 있습니다. 당일 종가가 없으면 보유분 평가에는 직전 확인된 종가를 사용합니다. 보유 종목을 평가할 수 없으면 날짜 진행·종료를 보류합니다.
- 주식은 Yahoo Finance chart 응답의 `close`와 `KRW=X` 환율을 사용합니다. 이는 안정성이 보장된 공식 공개 API가 아니므로 서비스 제한·형식 변경·연결 실패 시 데모로 전환될 수 있습니다. 통화와 종목 코드를 검증하고, 환율은 주가 날짜와 같거나 이전인 가장 최근 값(최대 7일 전)을 사용합니다. 미래 날짜의 환율은 사용하지 않습니다. 환전 수수료는 반영하지 않습니다.
- 주가 또는 환율 전체 조회 실패 시 해당 종목 전체 기간을 데모로 사용합니다. 정상 조회된 주식의 휴장일·누락일만 데모로 채우지 않습니다. 서버 실행 중에는 출처가 자동 변경되지 않도록 결과를 재사용하며, 데모에서 실제 데이터로 재시도하려면 서버를 재시작합니다. 재시작 후 평가 가격은 달라질 수 있지만 저장된 과거 체결 가격·출처는 보존됩니다.
- **코인은 되는데 주식 주문창이 없을 때:** 투자 날짜를 먼저 확인하세요. 예를 들어 2024-06-16은 일요일이므로 주식 주문이 없습니다. **내 자산 → +1일**로 2024-06-17로 진행해 확인할 수 있습니다. 실제 데이터에서는 미국 휴장일이나 데이터 누락일에도 주문을 제한합니다. 계좌 초기화는 필요하지 않습니다.
- 주식은 1주, 코인은 소수점 아래 8자리 단위입니다. 거래 금액과 종목별 평가액은 원 단위로 반올림합니다.
- 총자산 = 보유 현금 + 종목별 평가액 합계. 수익률 = (총자산 − 초기 투자금) ÷ 초기 투자금 × 100.
- 코치는 현금이 총자산의 10% 미만이면 낮음, 한 종목이 총자산의 50% 이상이면 집중으로 표시합니다. 매수·매도 횟수, 같은 날짜에 양방향으로 체결한 종목, 보유 종목 수를 함께 보여줍니다.
- 최대 낙폭은 저장된 평가 시점의 이전 최고점 대비 최대 하락률입니다. 날짜를 건너뛰면 사이 날짜의 자산은 별도 기록하지 않습니다. 코치는 Python 규칙으로 동작하는 교육용 기능입니다.
- Chart.js는 CDN을 사용합니다. CDN에 연결할 수 없으면 차트 자리에서 날짜별 가격 목록을 볼 수 있습니다.

## 테스트와 협업

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

자동 테스트는 임시 SQLite 파일과 예시 Upbit·주가·환율 응답을 사용하며 네트워크에 의존하지 않습니다. 일요일 주문 제한, 월요일 거래, 실제 데이터 우선 사용, 데모 전환과 출처 표시, 미래 환율 차단도 검사합니다. 자동 테스트만으로 실제 서버 연결이나 브라우저 Chart.js 렌더링을 검증한 것은 아닙니다.

| 경로 | 역할 |
| --- | --- |
| `app.py`, `templates/`, `static/` | Flask 요청, 웹 화면, 차트 |
| `market.py` | Upbit 일봉, 주식 역사 종가·환율 및 데모 대체, 거래일 및 차트 범위 |
| `trading.py`, `db.py` | 거래 검증, 잔액·보유량 반영, SQLite 저장 |
| `simulation.py` | 날짜 진행, 종료, 날짜별 자산 기록 |
| `coach.py` | 거래 및 자산 분석 규칙 |
| `tests/` | 화면 흐름, 가격, 거래와 상태 검증 |

V1은 ChatGPT로 제작한 기준 버전입니다. 팀원은 직접 실행해 본 결과를 남기고 개선 항목별로 Issue와 브랜치를 만든 뒤 PR로 제출합니다.
