## 검증 근거

- 11/19 로컬 Windows / Python 3.14.5: `python -m unittest discover -s tests -v` **25개 통과**. 임시 DB와 모의 공급자 응답 기반이며 실제 브라우저나 실시간 외부 API 검증과 다릅니다.
- 11/10 공개 HTTPS 검증 기록(PR #5): 화면·CSS·AAPL 매수/매도·계좌 분리 확인. 그때 AAPL은 데모, BTC는 실제 역사 시세였습니다. 이를 11/19 현재 공급자 상태로 재해석하지 않습니다.
- 11/19 Render 설정 조회: 동일 저장소, `deploy/team-web-access`, free, auto-deploy off. 이번 정비는 웹앱 런타임 파일을 변경하거나 재배포하지 않습니다.
- 현재 Git 추적 파일에 `.env`, SQLite DB, `.venv`는 없습니다. 이것은 비밀값이 절대로 없다는 보증이나 전문 보안 감사는 아닙니다.
- 라이선스 메타데이터와 LICENSE 파일이 없습니다. 공개 저장소라는 사실만으로 자유로운 재사용 라이선스가 부여된 것은 아닙니다.
