## 확인 가능한 요청과 한계

- 주식 오류 수정 요청: 실제 역사 데이터 우선, 실패 시 데모 명확 표시, 기존 코드·데이터 보존, 원인 확인 → 최소 수정 → 테스트 → 별도 브랜치/PR, main 병합 전 확인.
- 공유 요청: 팀원이 링크로 접속하도록 배포. 이후 사용자는 변경 화면을 먼저 보고 승인한 뒤 공개 사이트에 반영하도록 요청.
- 11/19 요청: 전달받은 평가 피드백을 검토하고 AI·본인·팀원의 일을 구분. 사용자가 확인한 팀 규모는 본인 포함 4명이며 이름은 제외.

위 내용은 요청의 **요약**이며 최초 프롬프트 원문이 아닙니다. 최초 생성 대화의 전체 프롬프트와 모든 팀 회의는 현재 문서 작성 시 확보하지 못했습니다. 원본 보유자가 제출 가능 범위를 확인해 원문/공유 링크를 추가해야 합니다. 추측한 프롬프트나 회의록을 실제 기록으로 만들지 않습니다.
