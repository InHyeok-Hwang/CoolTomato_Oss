# V2 시작 화면 검토안 · 2026-11-19

## 변경 전후

- 이전: `/` → 내 자산 → 계좌가 없으면 투자금·날짜 설정.
- 이후: `/`에 소개와 ‘투자 시작하기’ 버튼 → 기존 `/setup`.
- 계좌가 이미 있으면 `/setup`의 기존 동작으로 내 자산에 연결한다.
- 사이트 로고는 소개 화면으로 이동한다. 기존 거래·차트·시간 진행·결과 계산은 유지한다.

## 화면 구성

CoolTomato / 모의투자 시뮬레이터 / 과거로 돌아가 투자해 보세요.

소개 한 문단과 시작 버튼을 중심으로 배치하고, 아래에는 가상 투자금·과거 시세·규칙 기반 투자 코치 세 가지를 안내한다. 주식 데이터 조회 실패 시 데모가 사용된다는 사실도 명시한다. 상세 계좌·저장 제한 안내는 설정 화면에서 계속 제공한다.

## 범위와 비용

신규 소개 템플릿 1개, 기존 루트 경로와 공통 헤더 조정, 소개 화면 전용 CSS 및 기존 흐름 테스트 보완. 추가 외부 서비스·유료 자원은 생성하지 않았다. 이번 작업은 외주 금액 견적이 아니며 운영 요금 변경도 하지 않았다.

## 검증과 제한

- Windows 로컬 자동 테스트 25개 통과. 초기 실행은 임시 폴더 접근 제한으로 실패했으며 접근 가능한 환경에서 재실행해 통과했다.
- 실제 Flask 렌더링 HTML을 Edge에서 PC 1440px, 모바일 390px로 캡처했다. 두 너비 모두 가로 넘침 없음.
- 캡처는 로컬 정적 미리보기다. 파일 미리보기에서 설정 제출은 지원하지 않는다. 제출·거래 흐름은 Flask 테스트로 검증했다.
- 스크린샷은 로컬 `outputs/v2-preview/`에 있다. 공개 서버의 시세 연결과 실제 휴대폰 기기 테스트는 이번 검증에 포함하지 않았다.
- AI 보조 작업. 사용자 디자인 확인과 팀원 리뷰 전 main 병합·공개 배포하지 않는다.
